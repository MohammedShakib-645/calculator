## 📌 About

A fully functional **web-based calculator** with a sleek dark UI. Built from scratch using only vanilla HTML, CSS, and JavaScript — no libraries, no frameworks. The code is intentionally simple and human-readable.

This project demonstrates:
- DOM manipulation with JavaScript
- CSS Grid layout for button alignment
- Event handling (click + keyboard)
- Expression evaluation and error handling

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| ➕ ➖ ✖️ ➗ | All four basic arithmetic operations |
| **AC** | Clear everything (All Clear) |
| **DEL** | Delete the last character |
| **%** | Percentage calculation |
| **Keyboard Support** | Type numbers and operators directly |
| **Error Handling** | Displays `Error` for invalid expressions |
| **Floating Point Fix** | `0.1 + 0.2 = 0.3` not `0.30000000000004` |
| **Responsive UI** | Works on desktop and mobile |

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
